## Changes

- Python extractor v2 records import aliases/relative levels/star imports, dotted
  call targets, static __all__, definitions and shadow uncertainty without execution.
- Resolver v2 propagates re-exports to a monotone fixed point over stored facts.
  Direct alias/relative module bindings and star visibility are respected. Ambiguous
  stars, dynamic __all__, local shadowing and unsupported dynamic calls remain
  unresolved rather than inferred as definite dependencies. Top-level exports never
  silently include nested local functions.
- Delta relinks changed files and consumers of changed module/export bindings,
  including previously unresolved consumers. Body-only edits retain unrelated
  file ASTs and inferred edges. Global exports are derived from stored facts; no
  unchanged file source is parsed for that operation.
- apply_changes stages multiple file deltas privately and publishes one generation
  CAS only after cancellation and exact-source callback checks. Cancelled intermediate
  deltas cannot become visible. Publication sync uses this overlay and reads only
  supplied changed source paths on the ordinary owned path.
- ingest_source_changes adds non-Git content reconciliation; Git and watch paths
  remain hints. Dropped events/branch switches are caught by admitted full content
  audit at this explicit external trust boundary. No fast-path claim is made for
  arbitrary external writers. SourceWatcher.reconcile_graph ties reconciliation to
  current ready-event acknowledgment.
- build_tree/refresh_tree accept exact trusted owned changed_paths. File-level
  overlays read/hash/parse only those paths; changed definitions/module presence
  invalidate relevant legacy call/reference consumers; existing edges update fanin.
  Ignore/config or old-cache changes explicitly fall back to a full content audit.
- ActivationIndex.updated reuses unchanged node lexical token features, rebuilds
  exact postings/adjacency and marks PageRank invalidated. No approximate global
  score is labelled exact.
